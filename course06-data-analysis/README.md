# Course 6: Multimodal Data Extraction & Structuring

## 📌 Project Overview
Implemented a **Multimodal AI Data Pipeline** to extract unstructured text from an image and convert it into a structured database format.

---

## 🛠️ Problem & Solution
**The Problem:** 
It is often times monotonous and time-consuming to convert overly dense and technical data into clear and accessible information.

**The Solution:** 
Utilize multimodal prompting to isolate relevant variables from an image and the '=AI()' function to structure raw output into standardized columns.
This also eliminated the need to use complex formatting scripts.

---

## 📁 Featured Files:
- 'reviews-sample-screenshot.pdf': Orginal image used as the data input source
- 'structured-review-data.csv': Final database containing structured rows and columns extracted from the image by AI.

## 💡 Key Takeaways
By completing this project, I demonstrated:
- Proficiency in multimodal prompting
- Structured data creation using AI as a data pipeline tool
